# Vector DB Scraper

**Stack:** Python, ChromaDB

## Overview

A documentation scraping system that integrates with vector databases for semantic search and retrieval, utilizing local language models for query processing. It solves the problem of efficient document retrieval and analysis by leveraging vector similarity search and natural language query understanding.
