# AI Agent Orchestrator

**Stack:** Tmux, AI, Bash

## Overview

This project solves the problem of running AI agents 24/7 by utilizing tmux sessions for autonomous agent coordination and self-scheduling. The technical solution involves integrating tmux with the Claude API and using Bash and Python for automation.

## Engineering notes

This archive entry documents the reasoning behind ai agent orchestrator as a practical engineering exercise. The work emphasizes clear boundaries, useful feedback loops, and an implementation that can be inspected rather than treated as a black box. The selected technologies support the project's central constraint while keeping the system understandable for future iteration.

The project is also a record of trade-offs. It favors small, composable pieces, explicit interfaces, and a workflow that makes failures visible early. That approach makes it easier to test assumptions, compare alternatives, and improve the result without discarding the original learning. Where the work is exploratory, the archive preserves those limitations honestly so the next version can start from evidence instead of guesswork.
