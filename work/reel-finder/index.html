Reel-finder: retrieval for half-remembered saved content

Search for saved content using canonical ingestion, deduplication, keyword and multilingual semantic retrieval. Feedback and coverage checks make retrieval gaps inspectable. Private prototype; case study available.

Hybrid retrieval

keyword and multilingual semantic search

Solution and contribution

  • A single ingestion gateway: adapters produce raw items, canonical resource keys deduplicate links, and separate sightings retain source context.
  • Text acquisition from available captions, transcripts, OCR and page text; a staged pipeline records coverage gaps and reasons for missing content.
  • SQLite FTS5 keyword retrieval and multilingual-e5-large embeddings combined with reciprocal-rank fusion, exposed through a Python/FastAPI web interface.
  • Feedback labels, saved items, filters and stage telemetry. Development used coding-agent assistance; implementation and model choices are assessed against recorded evidence.

Verification and evidence

  • Source review confirms ingestion, retrieval and telemetry modules. Historical verification records distinguish actual application probes from unit tests.
  • Recorded hybrid MRR was 0.910 on a small single-user set of 70 agent-drafted, owner-confirmed queries. On a harder 62-query content-answerable note set, with notes excluded from the index, hybrid MRR was 0.496. These are different development sets, not a held-out public benchmark.
  • The latest recorded keyword/item probe passed on a scratch database. The standard hybrid probe failed after an embedding-model allocation error; that failure is unresolved in this showcase review.

Scope and current status

  • Personal exports, messages, media, databases, logs and private repository source are not published here.
  • No multi-user adoption, production-scale reliability, independent held-out benchmark, or completed general multimodal pipeline is claimed.
  • The headline retrieval score does not establish performance on vague owner wording; missing transcripts, partial vector coverage and model-memory failures remain real limits.
