# MERN ChatGPT Clone

**Stack:** MERN, React, Node.js

## Overview

This project is a full-stack MERN application that clones the functionality of ChatGPT, utilizing a thin client to proxy requests to OpenAI while managing state and user experience. The backend acts as a secure proxy, preventing direct API key exposure to the browser.
